- 2026-10-28 initial framework - NEUTRAL: first commit, no defects recorded yet. Tests are authored and run by test agents (see docs/changes).

Rule: enforce gates at the tool boundary (git pre-push), never only by parsing command text; any installer that overwrites or deletes must compare content hashes first; ask the test agent for adversarial bypass cases before the PM review.
